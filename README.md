# ANGULAR EXAMPLES - FRONTEND DEVELOPMENT

# PROJECT OVERVIEW:
This repository contains practical Angular examples and hands-on exercises developed while learning Angular frontend development.

It demonstrates fundamental Angular concepts through small examples and projects, helping build an understanding of component-based architecture and dynamic web application development.

# DESCRIPTION:
This repository focuses on practising Angular fundamentals and understanding how different Angular features work together to build interactive web applications.

It includes examples covering basic Angular application setup, components, data binding, and directives.

## WHAT THIS REPOSITORY CONTAINS:

## 1. BASIC APP
- Basic Angular application structure.
- Understanding Angular project organization.
- Introduction to Angular application development.

## 2. COMPONENT EXAMPLE
- Creating and using Angular components.
- Understanding component-based architecture.
- Organizing application functionality into reusable components.

## 3. DATA BINDING EXAMPLE
- Understanding data binding in Angular.
- Connecting component data with the application template.
- Practising communication between TypeScript and HTML templates.

## 4. DIRECTIVE DEMO
- Exploring Angular directives.
- Understanding how directives control HTML elements.
- Practising dynamic template behavior.
